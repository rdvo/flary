# Security policy

## Supported versions

Security fixes are released for the current `1.0.x` line. Users should run the latest patch release.

## Report a vulnerability

Use a private GitHub security advisory for sensitive reports:

https://github.com/rdvo/flary/security/advisories/new

Do not report a suspected vulnerability in a public issue, discussion, or pull request.

Include the affected Flary version, source commit when known, impact, sanitized reproduction steps,
and any known mitigation. Do not include live credentials, customer data, or unredacted logs.

The maintainers will confirm receipt, assess impact, prepare a fix, and coordinate disclosure.
Public details are released after users have a safe upgrade path.
