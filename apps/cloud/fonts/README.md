# Flary Sans

Flary Sans is the product typeface for Flary. It is a compact neo-grotesk for
interface text and large product headlines.

The design keeps conventional, readable lowercase forms. Its Flary voice comes
from tighter width, round punctuation and dots, a rounded `y`, crossed `K`,
straight-leg `R`, angled `M`, open `G`, extended `J`, open-tail `Q`, and a calmer
`2`. The result stays neutral in paragraphs and becomes recognizable at display
sizes.

The font uses one variable `wght` axis from 400 to 700. It supports the full
Western and Central European language set from its source family.

## Build

Run this command from the app directory:

```sh
npm run font:build
```

Generated files:

- `site-public/fonts/flary-sans-variable.woff2`
- `site-public/fonts/flary-sans-variable.ttf`
