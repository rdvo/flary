Research is a good first durable function because it can run after the caller
disconnects and can use bounded read-only tools in parallel.

## Define the function

```ts
import { flary, z } from "flary";

const app = flary<Env>({
  name: "research",
  model: "openai/gpt-5.6",
  bindings: z.object({
    OPENAI_API_KEY: z.string().min(1),
  }),
  auth: ({ request, bindings }) => authenticateResearcher(request, bindings),
});

const sources = app.tools({
  search: app.mcp({
    namespace: "sources",
    connection: "approved-sources",
  }),
});

export const research = app.fn({
  input: z.object({
    question: z.string().min(1),
    scope: z.string().min(1),
  }),
  output: z.object({
    answer: z.string(),
    citations: z.array(z.string().url()),
    uncertainty: z.string(),
  }),
  tools: sources,
  mode: "ask",
  thinking: "high",
  limits: { steps: 20, toolCalls: 40, timeoutMs: 600_000 },
  prompt: ({ question, scope }) => [
    "Research only from approved sources.",
    "Cite every material claim.",
    `Scope: ${scope}`,
    `Question: ${question}`,
  ].join("\n"),
});
```

Resolve the `approved-sources` connection in trusted host code with
`resolveMcp`. Keep it read-only. If the function must save a report, grant
only a plan-artifact capability.

## Serve and run it from a product

```ts
export default app.serve({ research });
```

```ts
import { flary } from "flary/client";
import type { research } from "./research";

const client = flary<{ research: typeof research }>({
  baseUrl: "https://research.example.com",
});

const run = await client.research.start({
  question: "Which vendors support SCIM provisioning?",
  scope: "Only approved security and vendor documentation.",
}, { idempotencyKey: "research:customer-42:scim:v1" });

for await (const event of run.stream()) {
  researchPanel.append(event);
}
```

For a large question, use bounded ask-mode child functions for independent
source groups. The parent must validate and cite child results before it
returns the final answer. See [Subagents and automation](/docs/subagents-and-automation/).
