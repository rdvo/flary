Use an agent for coding work that needs a persistent conversation and
workspace.

## Tools

```ts
import { app } from "./flary";

const github = app.mcp("github");

export const codingTools = app.tools({
  github,
  workspace: app.workspace({ branch: "run" }),
  shell: app.sandbox({ network: "restricted" }),
});
```

Workspace tools keep files and Git state. Sandbox tools run builds and long
processes. Both use the same lazy tool catalog and approval system.

## Agent and reviewer

```ts
import { app } from "./flary";
import { codingTools } from "./tools";

export const reviewer = app.agent({
  name: "reviewer",
  model: "openai/gpt-5.6-sol",
  instructions: "Review the current diff and report concrete defects.",
  tools: codingTools,
});

export const coder = app.agent({
  name: "coder",
  model: "anthropic/claude-sonnet",
  instructions: "Implement the task, run checks, and review the result.",
  tools: codingTools,
  subagents: { reviewer },
});

export const functions = { coder, reviewer };
export default app.serve(functions);
```

The Anthropic parent can delegate to the OpenAI reviewer. Each child has its
own durable thread, audit, usage, and mailbox.

## Create and reconnect

```ts
const thread = await api.coder.threads.create({
  title: "Add API rate limits",
});

await thread.send({
  message: "Inspect the API, add rate limits, and run the checks.",
});

for await (const event of thread.stream({ after: savedCursor })) {
  render(event);
  saveCursor(event.cursor);
}
```

Store the thread ID and newest cursor. The client does not resend the complete
conversation when it reconnects.

Each completed coding turn creates a workspace checkpoint. Products can list
the changed files, show a diff, or restore an earlier checkpoint. Git push and
pull-request actions still pass through tool policy and approval.
